# כוכבות החשבון — העלאה ל-Vercel + חשבונות ב-Supabase

אתר תרגול חשבון בעברית לכיתות א'–ו'. קובץ HTML אחד, בלי build ובלי קוד שרת.
החשבונות והסנכרון רצים ישירות מול Supabase מהדפדפן.

---

## מה יש בתיקייה

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה — קוד, עיצוב, גרפיקה ותוכן הלימוד |
| `config.js` | **הקובץ היחיד שצריך לערוך** — כתובת Supabase ומפתח anon |
| `supabase.sql` | הסכמה שצריך להריץ פעם אחת ב-Supabase |
| `manifest.json`, `icon-192.png`, `icon-512.png` | הפיכה לאפליקציה שמותקנת על מסך הבית |
| `vercel.json` | מבטיח שגרסה חדשה מגיעה לכולם מיד, בלי מטמון תקוע |

> אם משאירים את `config.js` ריק — האתר עובד מצוין בלי חשבונות,
> וההתקדמות נשמרת רק על המכשיר. אפשר להעלות ככה ולהוסיף חשבונות בהמשך.

## שלב 1 — Supabase (5 דקות)

1. היכנסו ל-[supabase.com](https://supabase.com) → **New project**.
   שם: `kochavot`. אזור: **Frankfurt** (הכי קרוב לישראל).
   שמרו את סיסמת מסד הנתונים בצד — לא נצטרך אותה כאן, אבל אל תאבדו אותה.

2. כשהפרויקט מוכן: **SQL Editor** → **New query** → הדביקו את כל התוכן של
   `supabase.sql` → **Run**. צריך לראות `Success`.

3. **חשוב מאוד** — כיבוי אישור אימייל.
   האפליקציה מייצרת כתובת פנימית (`שם-משתמש@kochavot.app`) כדי שילדים
   לא יצטרכו אימייל אמיתי. בלי הכיבוי הזה אף אחד לא יוכל להיכנס.

   **Authentication → Sign In / Providers → Email** →
   כבו את **Confirm email** → **Save**.

4. **Project Settings → API**. העתיקו שני ערכים:
   - `Project URL`
   - `anon` `public` key

5. פתחו את `config.js` והדביקו:

   ```js
   window.KOCHAVOT_CONFIG = {
     SUPABASE_URL: "https://xxxxxxxx.supabase.co",
     SUPABASE_ANON_KEY: "eyJhbGciOi..."
   };
   ```

   המפתח הזה גלוי בדפדפן וזה תקין — ההגנה היא ה-RLS שהרצתם בשלב 2.
   כל חשבון רואה אך ורק את השורה שלו.

## שלב 2 — GitHub

```bash
cd <התיקייה הזו>
git init
git add .
git commit -m "Kochavot HaCheshbon"
gh repo create kochavot --private --source=. --push
```

בלי `gh`: צרו רפו ריק ב-github.com ואז

```bash
git remote add origin https://github.com/<user>/kochavot.git
git branch -M main
git push -u origin main
```

## שלב 3 — Vercel

1. [vercel.com](https://vercel.com) → **Add New… → Project** → **Import** את הרפו.
2. Framework Preset: **Other**. Build Command: להשאיר **ריק**. Output Directory: להשאיר **ריק**.
3. **Deploy**.

תוך כדקה יש כתובת כמו `kochavot.vercel.app`. אפשר לחבר דומיין משלך
ב-**Settings → Domains**.

### עדכון האתר מכאן והלאה

```bash
git add . && git commit -m "עדכון" && git push
```

Vercel בונה מחדש אוטומטית, וכל מי שיפתח את הקישור יקבל את הגרסה החדשה
מיד — `vercel.json` דואג שהדפדפן לא יתקע על גרסה ישנה.
**ההתקדמות של המשתמשים לא נפגעת מעדכון** — היא יושבת בענן ובמכשיר,
לא בתוך הקוד, והאפליקציה יודעת לקלוט שדות חדשים על נתונים ישנים.

## שלב 4 — התקנה על הטאבלט

פותחים את הכתובת בספארי או בכרום → **שתף / תפריט** → **הוסף למסך הבית**.
מקבלים אייקון, מסך מלא בלי שורת כתובת, והתרגול הרגיל עובד גם בלי אינטרנט.

## איך עובדים החשבונות

- **חשבון אחד למשפחה** (שם משתמש + סיסמה, לפחות 6 תווים).
- בתוך החשבון יוצרים **פרופיל נפרד לכל ילד/ה** — שם, דמות, כיתה.
- כל ההתקדמות, ההישגים, האוספים והקניות נשמרים בענן ומסתנכרנים
  אוטומטית בין כל המכשירים שנכנסים לאותו חשבון.
- מי שלא רוצה חשבון לוחץ **"כניסה בלי חשבון"** — הכול נשמר מקומית,
  ויש קוד גיבוי ידני במסך "אני".

### איפוס סיסמה

אין שחזור סיסמה אוטומטי (אין אימייל אמיתי). כדי לאפס:
**Supabase → Authentication → Users** → מוצאים את המשתמש → `…` → **Reset password** /
או מוחקים את המשתמש ויוצרים מחדש. לפני מחיקה כדאי לקחת קוד גיבוי מהאפליקציה.

## כיתות ומעבר כיתה

לכל כיתה תוכנית משלה — שלושה נושאים, שמונה רמות בכל נושא:

| כיתה | נושאים |
|---|---|
| א' | חיבור וחיסור עד 20 · מספרים וסדר · בעיות קטנות |
| ב' | חיבור וחיסור עד 100 · כפל ראשון · בעיות מילוליות |
| ג' | חיבור וחיסור עד 1000 · לוח הכפל וחילוק · בעיות מילוליות |
| ד' | כפל וחילוק גדולים · שברים ראשונים · מידות ובעיות |
| ה' | שברים · עשרוניים ואחוזים · גיאומטריה וממוצע |
| ו' | שברים ויחס · אחוזים ועשרוניים · גיאומטריה ונפח |

בסוף שנה: **אני → מעבר כיתה ותעודות → "עלי לכיתה X"** (דורש אישור כפול).

- **נשמר:** תעודת "סיימתי כיתה X" עם סיכום השנה, וכל הכוכבים והפריטים שנקנו בחנות.
- **מתאפס:** הרמות, ההישגים, אוסף העונה ופרסי האירועים — מסע חדש בכיתה החדשה.

יש גם החלפת כיתה ידנית באותו מסך — משנה רק את התרגילים, בלי לאפס כלום.
שימושי אם הכיתה נבחרה בטעות.

## פתרון תקלות

**"החשבון ממתין לאישור"** — לא כיביתם את Confirm email (שלב 1.3).

**"אין חיבור לשרת כרגע"** — בדקו ש-`SUPABASE_URL` מתחיל ב-`https://` ובלי `/` בסוף.

**נכנסים ורואים פרופילים ריקים** — כנראה נכנסתם לחשבון אחר.
בדקו ב-Supabase → Authentication → Users איזה שם משתמש קיים.

**האתר לא מתעדכן אחרי push** — ב-Vercel תחת Deployments בדקו שה-deploy הצליח,
ואז רענון קשיח בדפדפן (Ctrl+Shift+R).
